# SnowPro Core 学習環境 with Claude Code

SnowPro Core（COF-C02）資格試験の学習と英語力向上を同時に行うための、Claude Code 活用型学習環境。

## 概要

英語の演習問題をClaude Codeに渡すと、以下を自動生成する:
- Snowflake技術用語の解説
- 英文法の詳細な解析
- 日本語訳
- 公式ドキュメントへのリンク
- サンドボックスでの検証手順

## ディレクトリ構成

```
study_with_claude/
├── CLAUDE.md              # Claude Codeへのプロジェクト指示書
├── questions/             # 問題ファイル（自動生成）
├── sandbox/
│   ├── setup/             # 初期セットアップSQL（共有テーブル等）
│   ├── exercises/         # 問題別SQLスクリプト（自動生成）
│   └── README.md          # 接続方法ガイド
├── docs/                  # 検証手順ドキュメント（自動生成）
├── progress/
│   └── tracker.md         # 進捗管理・間隔反復
├── reference/
│   ├── glossary.md        # 用語集（蓄積型）
│   ├── grammar_patterns.md # 頻出英文法パターン
│   └── exam_domains.md    # 試験ドメイン・出題比率
└── .claude/
    ├── settings.json      # フック設定
    └── skills/            # カスタムスキル（スラッシュコマンド）
```

## セットアップ

### 1. Snowflakeサンドボックスの準備
`sandbox/setup/` 内のSQLを順番に実行:
```
00_create_database.sql  → データベース・ウェアハウス作成
01_shared_tables.sql    → 共有テーブル作成
```

### 2. （任意）Snowflake MCP接続
Claude CodeからSnowflakeに直接接続したい場合:
1. `.mcp.json` のプレースホルダを自分のアカウント情報に書き換える
2. `uvx` (uv) がインストールされていることを確認
3. Claude Codeを再起動

詳細は `sandbox/README.md` を参照。

## 利用可能なスキル（スラッシュコマンド）

### `/question` — 問題の登録

演習問題をClaude Codeに渡して構造化ファイルを作成する。

**使い方:**
```
/question
[問題文、選択肢、解説をペースト]
```

**実行されること:**
- `questions/NNN_topic.md` を作成（9セクション構成）
- `progress/tracker.md` に追加
- `reference/glossary.md` に新しい用語を追加
- `reference/grammar_patterns.md` に新しいパターンを追加
- サンドボックス検証の要否を案内

**生成される問題ファイルの構成:**

| セクション | 内容 |
|-----------|------|
| 1-1. Snowflake用語解説 | 出現する技術用語の日本語解説（表形式） |
| 1-2. 重要コンセプトまとめ | この問題で理解すべきポイント |
| 1-3. 公式ドキュメントURL | Snowflake公式ドキュメントへのリンク |
| 2-1. 問題文（英語） | 原文をそのまま記載 |
| 2-2. 問題文の文法解析 | 文構造・語彙の詳細解説（日本語） |
| 2-3. 問題文（日本語） | 自然な日本語訳 |
| 3-1. 解説文（英語） | 原文をそのまま記載 |
| 3-2. 解説文の文法解析 | 文構造・語彙の詳細解説（日本語） |
| 3-3. 解説文（日本語） | 自然な日本語訳 |

---

### `/sandbox-doc` — 検証手順の作成

問題に対応するサンドボックス検証手順を作成する。

**使い方:**
```
/sandbox-doc 001_view_history
```

**実行されること:**
- `sandbox/exercises/NNN_topic.sql` を作成（実行用SQLスクリプト）
- `docs/NNN_topic.md` を作成（日本語の検証手順書）
- 共有テーブルの再利用を自動判断

---

### `/review` — 間隔反復レビュー

忘却曲線に基づいた復習セッションを実施する。

**使い方:**
```
/review        # 復習が必要な全問題
/review 5      # 5問だけ復習
```

**自信度レベルと復習間隔:**

| Level | 名称 | 復習間隔 |
|-------|------|----------|
| 1 | 低 | 1日後 |
| 2 | 中 | 3日後 |
| 3 | 高 | 7日後 |
| 4 | 完璧 | 14日後 |

**流れ:**
1. 復習対象の問題一覧を表示
2. 各問題についてリコール質問を出題
3. ユーザーの回答後、正解を表示
4. 自信度を自己評価（1-4）
5. 進捗トラッカーを自動更新

---

### `/progress` — 学習ダッシュボード

学習の全体像を可視化する。

**使い方:**
```
/progress
```

**表示内容:**
- 全体進捗（学習済み問題数、学習期間）
- ドメイン別カバレッジ（プログレスバー付き）
- 自信度分布
- 今後7日間の復習予定
- 弱点エリア（カバレッジ不足のドメイン、自信度の低い問題）
- 英語学習統計（用語数、文法パターン数）
- 推奨アクション

## 学習ワークフロー

```
┌─────────────────────────────────────────┐
│           過去問を解く                    │
└──────────────┬──────────────────────────┘
               ↓
┌─────────────────────────────────────────┐
│  /question で問題・選択肢・解説を渡す      │
└──────────────┬──────────────────────────┘
               ↓
┌─────────────────────────────────────────┐
│  questions/NNN_xxx.md が自動生成される     │
│  ・用語解説・文法解析・日本語訳・公式URL     │
└──────────────┬──────────────────────────┘
               ↓
┌─────────────────────────────────────────┐
│  /sandbox-doc で検証手順を作成             │
│  （手を動かす必要がある場合のみ）           │
└──────────────┬──────────────────────────┘
               ↓
┌─────────────────────────────────────────┐
│  docs/ で手順確認                         │
│  → Snowflakeサンドボックスで検証            │
│  （MCP / Cortex Code CLI / Snowsight）    │
└──────────────┬──────────────────────────┘
               ↓
┌─────────────────────────────────────────┐
│  定期的に /review で復習                   │
│  /progress で進捗確認・弱点把握            │
└─────────────────────────────────────────┘
```

## サンドボックス接続方法

| 方法 | 説明 | 適用場面 |
|------|------|----------|
| Snowsight（WebUI） | ブラウザでSnowflakeにログインし手動でSQL実行 | 基本はこれ |
| Snowflake公式MCP | Claude Codeから直接SQL実行 | 効率重視 |
| Cortex Code CLI | CLIツールで実行 | CLI好きな方 |

詳細は `sandbox/README.md` を参照。

## ファイル命名規則

すべての関連ファイルは同じ `NNN_topic` 命名を共有する:
- `questions/001_time_travel.md` — 問題ファイル
- `sandbox/exercises/001_time_travel.sql` — SQLスクリプト
- `docs/001_time_travel.md` — 検証手順

## Gitリポジトリに含まれないファイル

以下のファイル・ディレクトリは `.gitignore` で除外されています。

| 除外対象 | 理由 |
|---------|------|
| `questions/` | 著作権保護のため。試験問題・解説文の原文を含むため、リポジトリでの共有は行わない |
| `sandbox/exercises/` | 個人のサンドボックス環境に依存するSQLスクリプト。環境によって状態が異なるため共有しない |
| `docs/` | 各自の演習から生成された検証手順ドキュメント。個人の環境に依存するため共有しない |
| `.mcp.json` | Snowflakeの認証情報（アカウント・パスワード）を含むため |

`sandbox/setup/` 内の共通セットアップSQLは追跡対象です。

## MCP設定

`.mcp.json` のプレースホルダを書き換えて使用:
- `<YOUR_SNOWFLAKE_ACCOUNT>` — Snowflakeアカウント識別子
- `<YOUR_USERNAME>` — ログインユーザー名
- `<YOUR_PASSWORD>` — パスワード

`.mcp.json` は `.gitignore` で除外済み（認証情報を含むため）。

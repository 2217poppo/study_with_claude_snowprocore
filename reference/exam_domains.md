# SnowPro Core Exam Domains

SnowPro Core 認定試験（COF-C02）のドメイン構成と出題比率。

## ドメイン一覧

| Domain | Name | Weight |
|--------|------|--------|
| 1 | Snowflake Cloud Data Platform Features & Architecture | 25% |
| 2 | Account Access and Security | 20% |
| 3 | Performance Concepts | 15% |
| 4 | Data Loading and Unloading | 10% |
| 5 | Data Transformations | 20% |
| 6 | Data Protection and Data Sharing | 10% |

## Domain 1: Snowflake Cloud Data Platform Features & Architecture (25%)
- Snowflakeのアーキテクチャ（ストレージ、コンピュート、クラウドサービス）
- エディション（Standard, Enterprise, Business Critical, VPS）
- クラウドプラットフォーム（AWS, Azure, GCP）
- データ共有、マーケットプレイス
- Snowflakeのオブジェクト階層

## Domain 2: Account Access and Security (20%)
- ユーザー、ロール、権限管理
- RBAC（ロールベースアクセス制御）
- ネットワークポリシー
- MFA、SSO、フェデレーション認証
- データ暗号化

## Domain 3: Performance Concepts (15%)
- ウェアハウスのサイズとスケーリング
- クラスタリングキー
- マテリアライズドビュー
- リザルトキャッシュ
- クエリプロファイル

## Domain 4: Data Loading and Unloading (10%)
- ステージ（内部・外部）
- COPY INTO コマンド
- Snowpipe（自動取り込み）
- ファイルフォーマット（CSV, JSON, Parquet等）
- データアンロード

## Domain 5: Data Transformations (20%)
- SQL関数（集約、ウィンドウ、文字列、日付等）
- ストアドプロシージャ
- UDF / UDTF
- タスクとストリーム
- ビュー（通常、セキュア、マテリアライズド）

## Domain 6: Data Protection and Data Sharing (10%)
- Time Travel
- Fail-safe
- データ複製
- データ共有（プロバイダー/コンシューマー）
- データマスキング

# SnowPro Core Exam Domains

SnowPro Core 認定試験（COF-C03）のドメイン構成と出題比率。

## 試験概要

| 項目 | 内容 |
|------|------|
| 試験バージョン | COF-C03 |
| 問題数 | 100問 |
| 問題形式 | 複数選択・単一選択 |
| 制限時間 | 115分 |
| 合格スコア | 750以上（0〜1000のスケールスコア） |
| 受験料 | $175 USD |
| 前提条件 | なし |

## ドメイン一覧

| Domain | Name | Weight |
|--------|------|--------|
| 1 | Snowflake AI Data Cloud Features & Architecture | 31% |
| 2 | Account Management and Data Governance | 20% |
| 3 | Data Loading, Unloading, and Connectivity | 18% |
| 4 | Performance Optimization, Querying, and Transformation | 21% |
| 5 | Data Collaboration | 10% |

## Domain 1: Snowflake AI Data Cloud Features & Architecture (31%)

- Snowflakeのアーキテクチャ（ストレージ、コンピュート、クラウドサービス）
- エディション（Standard, Enterprise, Business Critical, VPS）
- クラウドプラットフォーム（AWS, Azure, GCP）
- Virtual Warehouse の管理・設定
- Snowflakeのオブジェクト階層
- AI/ML機能（Cortex等）
- Snowsightなどのツール・インターフェース

## Domain 2: Account Management and Data Governance (20%)

- ユーザー、ロール、権限管理（RBAC）
- ネットワークポリシー
- MFA、SSO、フェデレーション認証、SCIM
- データ暗号化・セキュリティ
- データマスキング・行アクセスポリシー
- タグ付けとデータ分類
- アカウント使用状況の監視

## Domain 3: Data Loading, Unloading, and Connectivity (18%)

- ステージ（内部・外部）
- COPY INTO コマンド
- Snowpipe（自動取り込み）
- ファイルフォーマット（CSV, JSON, Parquet等）
- データアンロード
- コネクタ・ドライバ（JDBC, ODBC, Python等）
- SnowSQL（CLI）

## Domain 4: Performance Optimization, Querying, and Transformation (21%)

- Virtual Warehouseのサイズとスケーリング
- クラスタリングキー
- マテリアライズドビュー
- リザルトキャッシュ・メタデータキャッシュ
- クエリプロファイル
- SQL関数（集約、ウィンドウ、文字列、日付等）
- ストアドプロシージャ・UDF / UDTF
- タスクとストリーム
- ビュー（通常、セキュア、マテリアライズド）

## Domain 5: Data Collaboration (10%)

- データ共有（プロバイダー/コンシューマー）
- Snowflake Marketplace
- Time Travel
- Fail-safe
- データ複製・レプリケーション
- クリーンルーム

# 間隔反復レビュー

復習時期が来た問題を抽出し、復習セッションを実施する。

## 間隔反復ルール
- Confidence 1（低）: 1日後にレビュー
- Confidence 2（中）: 3日後にレビュー
- Confidence 3（高）: 7日後にレビュー
- Confidence 4（完璧）: 14日後にレビュー

## 手順

### Step 1: 進捗トラッカーの読み込み
`progress/tracker.md` を読み、今日の日付と各問題の Next Review 日を比較する。
Next Review が今日以前の問題が復習対象。

### Step 2: 復習対象の一覧表示
復習が必要な問題を一覧で表示する（日本語）:
- 問題番号とトピック
- ドメイン
- 前回の自信度
- 最終レビューからの経過日数

引数で件数が指定されていれば、自信度が低い順にその件数だけ表示。

### Step 3: 各問題の復習
復習対象の問題ごとに:
1. tracker.md のセクションを確認し、該当問題ファイルを Glob で検索して読み込む:
   - `## Questions` セクションの問題 → `all_questions/questions/NNN_*.md` を検索
   - `## Questions_2` セクションの問題 → `all_questions/questions_2/NNN_*.md` を検索
   - 読み込むのは 1-1（用語解説）と 1-2（重要コンセプト）
2. ユーザーに対して、**以下の3種類のいずれか**の質問を日本語で出す。問題ごとに種類を選ぶ

   **【種類A】用語説明（記述式）** — 1つの用語を説明させる。複数の概念を組み合わせたり、2つの用語の比較、「〜できることを3つ挙げてください」のような複合的な問いは禁止。
   - OK例：「ディレクトリテーブルとは何ですか？」
   - NG例：「Time TravelとFail-safeの違いを説明してください」（2つの用語の比較は禁止）
   - NG例：「Snowflakeがデータを内部保存する際にユーザーができることとできないことを3つ以上答えてください」

   **【種類B】穴埋め・数値（短答式）** — 具体的な値・名称を答えさせる
   - 例：「Time Travelのデフォルト保持期間は何日ですか？」
   - 例：「Virtual WarehouseのサイズはX-Smallから最大何サイズまでありますか？」

   **【種類C】選択肢（4択）** — A/B/C/Dの選択肢を提示する。正解は1つ。選択肢は問題ファイルの内容から自然に作成する
   - 例：「Snowflakeのストレージレイヤーはどれですか？ A) Amazon S3 / Azure Blob / GCS　B) Virtual Warehouse　C) Query Engine　D) Cloud Services」

3. ユーザーの回答を待つ
4. 正解を表示し、問題ファイルの該当セクションを参照として示す
5. ユーザーに自信度（1-4）を自己評価してもらう

### Step 4: トラッカーの更新
各問題について:
- Last Review を今日の日付に更新
- Confidence をユーザーの自己評価に更新
- Next Review を自信度に基づき計算して更新

### Step 5: セッションサマリー
復習セッション終了後、以下を表示:
- 復習した問題数
- 自信度の変化（上がった/下がった/変わらず）
- 次回復習が必要な問題と日付

## 1-1. Snowflake用語解説

| 用語 | 説明 |
|------|------|
| Business Intelligence Partner | SnowflakeエコシステムのBIツール提供ベンダー。データ可視化・分析ダッシュボードを提供 |
| Tableau | Salesforce傘下のBI可視化ツール。Snowflakeの主要BIパートナー |
| PowerBI | MicrosoftのBIツール。Snowflakeと統合可能 |
| Looker | Google Cloud傘下のBIプラットフォーム |
| MicroStrategy | エンタープライズBI・分析プラットフォーム |
| Oracle | BI機能を含むエンタープライズソフトウェアベンダー |

## 1-2. 重要コンセプトまとめ

- Snowflakeの主要BIパートナー: **Tableau, PowerBI, Looker, MicroStrategy, Oracle** など多数
- 試験では「全部正解」のパターンがある — 全選択肢がBIパートナー
- SnowflakeはBI・ETL・データ統合など多数のパートナーエコシステムを持つ

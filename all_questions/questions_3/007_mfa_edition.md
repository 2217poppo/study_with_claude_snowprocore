# 007: MFA Edition

**SnowPro Core Domain**: Domain 1 — Snowflake AI Data Cloud Features & Architecture
**作成日**: 2026-04-15
**正答**: Standard

---

## 1-1. Snowflake用語解説

| 用語 | 説明 |
|------|------|
| MFA (Multi-Factor Authentication) | 多要素認証。パスワードに加えて追加の認証要素を要求するセキュリティ機能。すべてのエディションで利用可能 |

## 1-2. 重要コンセプトまとめ

- MFAは**全エディション対応**（最小Standard）
- セキュリティの基本機能は通常すべてのエディションでサポートされる
- ACCOUNTADMINにはMFA必須が推奨

## 1-3. 公式ドキュメントURL

- [Snowflake Editions](https://docs.snowflake.com/en/user-guide/intro-editions)

## 2-3. 問題文（日本語）

> MFA（多要素認証）をサポートする最小のSnowflakeエディションは？

---

## 3-1. 解説文（英語）

> All Snowflake editions support MFA; thus, the minimum edition that supports it is the Standard edition.

## 3-3. 解説文（日本語）

> すべてのSnowflakeエディションがMFAをサポートしています。したがって最小エディションはStandardです。
